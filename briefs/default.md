Find the one project this person should build next. Where this brief and their profile disagree, the profile wins.

A good idea:

- serves the goal in their profile, whether that is GitHub stars, real users, income or something else
- fits their skills, time, budget and taste
- has an audience big enough to matter, and a first version they can ship in a few weeks
- shows its value fast: one screenshot, GIF, command or demo
- isn't something they have already built

Out of scope unless the profile asks for it:

- ideas that need a sales team, partnerships or paid infrastructure before they're useful
- another general-purpose agent framework, chat UI or "awesome" list
